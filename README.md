# UGC Actor Profile Generator

A Claude Code / Claude skill that generates hyper-realistic, conversion-optimized AI actor profiles for UGC (user-generated content) video ads — complete with physical description, personality, voice profile, platform fit, ad strategy guidance, and ready-to-use image generation prompts (for fal.ai flux-pro, DALL-E 3, etc.).

## What it does

Given filters like actor type, gender, age range, skin tone, style, niche, and count, this skill produces full casting-director-grade actor profiles you can hand straight to an image generator and a scriptwriter — no guessing required.

Each profile includes:
- Identity (name, age, location, background)
- Physical description
- Personality & on-camera presence
- Voice profile
- Content & conversion intelligence (best formats, niche fit, platform fit)
- Strategic ad guidance (hook style, script tone, brand voice match, anti-match warnings)
- Copy-paste-ready studio and lifestyle image generation prompts

## Usage

Install as a Claude skill (`SKILL.md`) and invoke it (e.g. `/ugc-actor`) when you want to design or generate AI actors for UGC ads, TikTok/Instagram creatives, or social video marketing.
